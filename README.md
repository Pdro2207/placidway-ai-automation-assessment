PlacidWay AI Social Media Automation

Documentation and source code for an automated social media publishing pipeline built for PlacidWay using Make.com and Google Gemini AI, developed as part of an AI Automation Engineer technical assessment.

Workflow Architecture

The automation scenario runs three sequential modules:

1. HTTP Module (Article Ingestion)
- Automatically fetches text and HTML content from the target PlacidWay article URL (https://www.placidway.com/article/9796/Why-Families-Are-Researching-Stem-Cell-Therapy-for-Autism-in-Mexico-What-Evidence-Should-They-Ask-For)

2. Google Gemini AI Module (Content Generation & Guardrails)
- Processes the retrieved HTML data using the Gemini 3.8 Flash model.
- Restructures the content into an engaging social media post format (Hook, Value Proposition, Call-to-Action, and Hashtags).
- Enforces strict medical compliance guardrails.

3. Facebook Pages Module (Automated Publishing)
- Takes the structured text output generated by Gemini.
- Automatically publishes the post directly to the target Facebook Page (Pedro).

Medical Guardrails and Prompt Engineering

The system prompt is specifically engineered to ensure compliance and safety:
- Strict Non-Guaranteed Outcomes: Prohibits claims or promises regarding medical treatment success rates.
- No Price Hallucinations: Forbids generating pricing or cost details unless explicitly stated in the source text.
- Factual Adherence: Restricts content strictly to factual information extracted from the source article.
- Length Optimization: Keeps output under 500 characters for optimal social media readability.

Deliverables

- PlacidWay_SocialMedia_Automation_Blueprint.json: The Make.com scenario blueprint file ready for re-importing.
